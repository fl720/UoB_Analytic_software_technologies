# Introductory Python notebooks

These notebooks accompany a short Python introduction for new students on:

- MSc Advanced Machine Learning
- MSc Artificial Intelligence
- MSc Data Science

The repository contains three notebooks:

1. `01_basic_python.ipynb`: Python fundamentals
2. `02_data_structures_numpy_pandas.ipynb`: files, modules, NumPy and pandas
3. `03_intro_machine_learning_sklearn.ipynb`: a first introduction to machine learning with scikit-learn

Each notebook contains runnable examples and short exercises. Exercise solutions are collected in a separate section at the end of each notebook, so you can attempt the exercises before checking your work.

## Setup

Install Python, clone or download this repository, then run:

```bash
python -m pip install -r requirements.txt
```

Then open the notebooks with either `jupyter lab` or your favourite IDE and work through them from top to bottom.
